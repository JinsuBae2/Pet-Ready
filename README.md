# 🐶 스마트 로봇견 제어 통합 시스템 (DOG_01) 

ESP32와 각종 센서를 활용하여 백엔드 서버 및 비전 AI(v2.3)와 통신하는 스마트 로봇견 제어 시스템입니다. 

## ✨ 최근 업데이트 (v2.3 연동 패치 반영)
팀 PR 리뷰 결점 리포트를 바탕으로 아래의 치명적 연동 이슈를 모두 해결했습니다.
1. **기기 식별자 동기화**: 백엔드 및 비전 AI 훈련 매핑 기준에 맞춰 `DEVICE_ID`를 `DOG_01`로 수정했습니다.
2. **서버 송신 텍스트 파싱 적용**: 서버 상태 응답 DTO에서 `lcdTextLine1`, `lcdTextLine2`, `lcdCommand` 필드를 파싱하도록 통신부를 보완했습니다.
3. **실시간 아스키 이모지 및 상태 표출**: 고정된 픽셀 그래픽 출력을 제거하고, 서버가 빌드해 주는 텍스트를 16x2 LCD에 그대로 렌더링합니다. (3초 락아웃 훈련 피드백 및 6대 다마고치 감정 정상 표출 / 화면 깜빡임 방지 로직 적용)
4. **상태 표시 LED 로직 정상화**: 평상시에는 초록불(Green)이 켜지며, 서버 경고(RED), 짖기 미션, 음성인식 실패 시에만 즉각적으로 빨간불(Red)이 켜지도록 개선했습니다.

## 🛠 주요 기능 (Features)
* **실시간 LCD 텍스트 출력**: 서버 연동을 통한 실시간 상태 및 훈련 보상 피드백 텍스트 표출
* **터치 상호작용**: FSR 압력 센서를 이용해 머리 쓰다듬기, 등 터치 등 사용자의 상호작용 인식 및 즉각적인 상태 보고
* **오디오 재생**: SD 카드 버퍼링을 통한 MP3 재생 (짖기 미션, 앓는 소리 등)
* **젯슨 나노 연동**: 비전 및 음성 인식 실패 시그널(`UNKNOWN_CMD`) 수신 및 상태 반영

## 📡 서버 통신 및 폴링(Polling) 구조
본 프로젝트는 서버 부하를 줄이고 안정성을 높이기 위해 아래와 같은 통신 아키텍처를 가집니다.

* **동적 명령어 폴링 (Dynamic Polling)**
  * 기본적으로 30초 주기(`commandPollInterval`)로 서버에 명령을 요청합니다.
  * 서버의 응답 JSON에 포함된 `nextPollIntervalSec` 값을 파싱하여 다음 폴링 주기를 유동적으로 조절함으로써 불필요한 트래픽을 방지합니다.
* **오프라인 데이터 버퍼링 (Offline Buffer)**
  * Wi-Fi 또는 서버 연결이 끊겼을 때, 센서 상태 데이터를 SD 카드의 `/buffer.txt`에 임시 저장합니다.
  * 통신이 복구되면 모아둔 데이터를 서버로 일괄 전송(Burst 송신)하여 데이터 유실을 방지합니다.

## 💻 사용된 라이브러리 (Dependencies)
* `WiFi.h`, `HTTPClient.h` : REST API 통신
* `ArduinoJson` : JSON 데이터 파싱 및 생성
* `ESP32-audioI2S` (`Audio.h`) : I2S 오디오 출력
* `LiquidCrystal_I2C` : 1602 LCD 제어
* `SD_MMC.h` : 오디오 파일 및 오프라인 버퍼용 SD 카드 제어

## 🚀 설치 및 실행 방법 (How to Use)
본 저장소에는 보안을 위해 민감한 Wi-Fi 및 서버 정보가 제외되어 있습니다. 코드를 실행하려면 아래 단계를 따라주세요.

1. 본 저장소를 다운로드(Clone) 합니다.
2. `secrets_example.h` 파일의 이름을 `secrets.h` 로 변경합니다.
3. `secrets.h` 파일을 열고 본인의 환경에 맞게 정보를 수정합니다.
   ```cpp
   // secrets.h 예시
   #ifndef SECRETS_H
   #define SECRETS_H
   const char* ssid = "본인의_와이파이_이름";
   const char* password = "와이파이_비밀번호";
   const char* BASE_URL = "http://서버_IP주소:포트";
   #endif
